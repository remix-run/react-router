## 👋 Welcome to React Router

React Router is a multi-strategy router for React. You can use it maximally as a React framework or minimally as a library with your own architecture.

### 🚀 Getting Started

Choose the approach that works best for your application.

| 🏗️ Framework | 🧩 Library |
| :--- | :--- |
| Use React Router as a React framework. | Use React Router as a library with your own architecture. |
| [**Getting Started - Framework**](https://reactrouter.com/start/framework/installation) | [**Getting Started - Library**](https://reactrouter.com/start/library/installation) |

**More resources**
