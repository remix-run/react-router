# Vendored route-pattern matcher

This is the pathname-matching subset of `@remix-run/route-pattern@0.22.1`,
vendored from Remix tag `route-pattern@0.22.1` at commit
`8bace0a1044a6a98b3e56a38a1db9b2f9aff4ff1`.

Tests for protocol, hostname, port, search, URL generation, URL joining, and
type-level APIs were removed with their implementations. The retained upstream
test cases are unchanged so improvements can be contributed upstream before
the React Router flag stabilizes.
